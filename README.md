# 智鉴风控官 Web（zhijian-risk-web）

多组织 Web 工作台，对应桌面端 axiom-risk-agent 的核心能力：

- 总览、风险吹哨、经营守护、准入瞭望、机构名单、规则库、问鉴控、设置
- 组织与成员（数据按组织隔离；创建组织和分配成员仅系统管理员）
- 线索台账（从总览或头像菜单进入）

## 技术栈

- 前端：Vue 3 + Vite + Pinia + Vue Router
- 后端：Spring Boot 3 + Spring Security JWT + MyBatis-Plus
- 数据库：MySQL。连接写在 `backend/src/main/resources/application.yml`，表结构见 `backend/src/main/resources/db/mysql/schema.sql`。已有库不要重复执行该脚本。启动时若准入、吹哨、经营、问鉴控的正文和 JSON 列过短，会自动改成 `LONGTEXT`。

## 接口

成功和失败都是同一套信封：

```json
{ "code": 0, "message": "ok", "data": {} }
```

- `code` 为 0 表示成功。失败时 `code` 与 HTTP 状态一致，`message` 是原因，`data` 为 `null`。
- Controller 方法直接返回 `ApiResult<T>`。全局异常处理器负责失败信封，访问日志由切面记录。
- 前端 axios 拦截器取出 `data`，页面按业务对象使用；错误读 `message`。
- 机构名单、规则库提供 `.xlsx` 模板下载和导入。机构按全称更新，规则按编码更新；编码留空则新增。单文件不超过 5MB，一次最多 2000 行。文件下载不套信封。
- 准入瞭望、风险吹哨、经营守护的报告在页面上按 HTML 排版显示，可导出独立 HTML 文件，也可以打印。
- 准入评审同时使用已启用的百度搜索、企查查和天眼查。名单里有统一社会信用代码时，工商查询用代码。这三路和上传材料都没有时，结论为待核验。全网搜返回的网页若未点名本公司或标题没有风险词，不作为证据，但会列在意见书的「全网搜」一节。报告按桌面端准入意见书排版，检查清单只列出触发项。大模型请求使用 HTTP/1.1，握手失败会再试一次。已生成的旧报告不会自动重写。
- 准入和经营守护可以上传财报或尽调附件（.docx / .xlsx / .xls / .csv / .txt）。准入可多选，正文与全网搜、工商信息一起研判。暂不支持 PDF 和旧版 .doc。经营守护可留空机构名，由附件识别。已填写的名称和期间不会被模型改写；未从名单选择、且附件识别为融资担保时，才把默认助贷改为融担。同一机构同一期间重新分析会覆盖上一份。同业对比和历史时序与桌面端同一口径。名单里还没有关联方字段，穿透提示与桌面端「关联方为空 / 未绑定名单」一致。
- 风险吹哨可出日报、周报，按全部或指定机构跑批。定时保存在组织设置里，到点自动跑一次。线索可以改等级或人工关闭。
- 设置页的大模型、百度搜索、企查查、天眼查可以测试连接。密钥框留空时用已保存的密钥，测试和保存都不会把空密钥写回去。保存后输入框仍保留本次填写的内容；刷新页面后接口不回传密钥，框内显示「已配置」。大模型先请求 `/chat/completions`，若返回 404 再请求 `/responses`。

## 启动

```bash
# 后端
cd backend && mvn spring-boot:run

# 前端
cd frontend && npm install && npm run dev
```

- 前端：http://localhost:5173
- 后端：http://localhost:8080

用户表为空时才会写入演示账号。库里已有用户时不会覆盖，需要先注册。

| 用户 | 密码 | 说明 |
|------|------|------|
| admin | Admin@123 | 平台管理员，可创建组织并分配成员 |
| alice | User@123 | 演示操作员 |
| bob | User@123 | 演示复核员 |

登录后选择组织。在「设置」中配置大模型与百度搜索 Key 后，吹哨、经营守护、准入瞭望、问鉴控走真实研判。
